Quick Help

How do we play on one device?

Choose Together on the home screen, then pick a game. Card games may hide the next player's cards behind an I'm ready screen. Pass the device before continuing. The question-mark button opens each game's rules.

How do we connect nearby devices?

Install the same app version on both devices. Choose Nearby and the same game on each. One player chooses Host game; the other chooses Find a game and selects the host. Allow Local Network permission in iOS Settings and keep Wi-Fi and Bluetooth enabled. Try both devices on the same Wi-Fi network. Nearby play supports two players.

How do we play during FaceTime?

Start a two-person FaceTime call, with SharePlay enabled on both devices. Open Face2Face, select FaceTime mode, choose a game, and confirm Apple's SharePlay prompt. The other player accepts the invitation and joins in Face2Face. Wait for both players to connect. Together mode does not start SharePlay.

If the game will not connect, check that both devices have the same app version and that SharePlay is allowed in FaceTime settings. End the shared activity and try again. If it still fails, email the game, device models, iOS versions, and connection steps so I can investigate.

Why can't I move a puzzle piece?

Tap one piece, then the piece you want to swap with it. The reference picture and lightbulb hint can help. Start with the smallest puzzle size while learning.

Can I use my own photo?

Yes. Photo Puzzle uses Apple's photo picker so you choose the image, without granting access to the whole photo library. In a shared game, that picture is sent to the other player. Only choose a photo you want them to see.

Are there ads or purchases?

No. Face2Face Games is free, with no ads, accounts, subscriptions, or in-app purchases. Support and developer links in Settings require a grown-up check before leaving the app.

Where is the new icon?

The current redesign uses coral and teal smiling game tiles with a yellow pawn. Apple's store or TestFlight listing may display different artwork from the installed app. Check the installed version in Face2Face Settings; if its Home Screen icon is wrong, send a screenshot and build number to support.
